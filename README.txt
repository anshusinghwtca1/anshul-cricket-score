# Anshul Cricket Score

A small personal live-cricket-score webpage.

## How it works
- Uses CricketData.org Current Matches API.
- You need your own free API key.
- The key is stored only in the browser's localStorage.
- No WhatsApp automation, modified WhatsApp, scraping bot, or unofficial WhatsApp client is included.

## Important
The free CricketData plan currently lists 100 API hits/day. Avoid aggressive automatic polling.

## API
https://api.cricapi.com/v1/currentMatches?apikey=YOUR_API_KEY&offset=0

Provider:
https://cricketdata.org/
